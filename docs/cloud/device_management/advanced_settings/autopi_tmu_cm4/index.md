This guide will walk you through accessing and configuring advanced settings for your AutoPi TMU CM4 device. Customize device behavior, power management, data logging, network configuration, and specialized features to optimize your device for your specific operational needs. Learn how to access configuration options and understand the settings available to control your device's functionality.

![AutoPi Cloud Advanced Settings](/img/cloud/device_management/advanced_settings/autopi_tmu_cm4/intro/advanced_settings_updated.png)



:::tip
Like any AutoPi [Cloud](https://www.autopi.io/software-platform/cloud-management) functionality, configuration settings can be changed programmatically through the AutoPi REST API. For more information see our [API docs page](https://api.autopi.io/).
:::

You can control a lot of different things on the device. Each of the settings is explained in details on the following pages.
