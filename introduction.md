# Changelog

Welcome to our monthly changelogs. Each month, we organize and document all changes to the AutoPi platform across our **Frontend**, **Backend**, and **Core** systems.

## What You'll Find Here

This section contains the complete, raw changelogs for each monthly release, pulled directly from our GitLab repositories. These pages provide comprehensive technical details about every change, including:

- All new features and enhancements.
- Bug fixes and stability improvements.
- Refactoring and internal updates.
- Other technical changes.

## Navigating Releases

Each month has two views:

- **Changelog** (this section) — the technical, unfiltered view of all changes across all systems.
- **Releases** — a curated, user-friendly summary highlighting the most important new features, bug fixes, and improvements with screenshots and descriptions.

We recommend starting with the Releases page for a better overview, then referring to the Changelog for deeper technical details.
